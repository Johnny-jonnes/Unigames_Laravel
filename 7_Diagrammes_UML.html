3. Diagramme de Séquence (Saisie d'un Résultat)

sequenceDiagram
    actor S as Staff
    participant V as Vue Blade (match/show)
    participant C as MatchController
    participant DB as Base de Données

    S->>V: Ouvre la page de détails du match
    V-->>S: Affiche le formulaire de score (car non joué)
    S->>V: Remplit score A/B et ajoute dynamiquement des buteurs
    S->>V: Clique sur "Enregistrer le résultat final"
    V->>C: POST /matchs/{id}/score (Données)
    C->>C: Validation (Request) + Application Middleware CanManage
    C->>DB: UPDATE matchs SET score_a, score_b, buteurs(JSON), statut='joue'
    DB-->>C: Requête SQL OK
    C-->>V: Redirection vers index avec message de succès
    V-->>S: Affiche les nouveaux scores, badges et buteurs
